# Pictures

Illustrations for the game. Register new ones in `js/story.js` under `art` (see `WRITING.md`), and always write alt text.

## In the game now

| File | Used on | Notes |
| --- | --- | --- |
| `mouse.svg` | title screen, mouse hole, the mice, left click | starter drawing |
| `hot-chocolate.svg` | title screen, "A cosy hot chocolate", page icon | starter drawing (the binary on the mug says HI) |
| `paperclip.svg` | Clippy's passages | starter drawing |
| `chocolate-mouse.svg` | the final ending | starter drawing |
| `encoding.png` | "But why?! Binary, ASCII and hex" | from the original game |

The starter drawings are simple placeholders. Replace any of them with nicer artwork by saving over the file, or by adding a new file and changing its `src`.
